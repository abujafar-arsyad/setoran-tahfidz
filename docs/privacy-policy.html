Kebijakan Privasi — Setoran Tahfidz

Berlaku sejak 4 November 2026 · diperbarui 6 November 2026

Setoran Tahfidz adalah aplikasi pencatat hafalan Al-Qur'an yang berjalan sepenuhnya secara offline di perangkat Anda.

Data yang dikumpulkan

Tidak ada. Aplikasi ini tidak mengumpulkan, mengirim, membagikan, atau menyimpan data pengguna di server mana pun. Aplikasi tidak memiliki backend, tidak melakukan panggilan jaringan apa pun, dan tidak menyertakan SDK analitik, iklan, atau pelacak pihak ketiga.

Penyimpanan data

Seluruh data yang Anda masukkan (misalnya nama santri dan halaqah, catatan setoran, nilai, dan pengaturan) disimpan hanya di perangkat Anda sendiri, menggunakan penyimpanan lokal WebView (localStorage). Data tersebut:

  • Tidak pernah dikirim ke server dan tidak dapat diakses oleh pengembang aplikasi.
  • Tidak ikut dicadangkan otomatis oleh Android (cadangan otomatis dimatikan).
  • Akan terhapus jika Anda menghapus data aplikasi atau meng-uninstall aplikasi.

Data hanya keluar dari perangkat bila Anda sendiri memilih mengekspor file cadangan atau membagikan gambar laporan/rapor lewat menu bagikan Android. File tersebut dikirim ke aplikasi atau tujuan yang Anda pilih, bukan ke pengembang.

Izin aplikasi

Aplikasi ini tidak meminta izin khusus apa pun (tidak ada akses kamera, lokasi, kontak, internet, dan sebagainya) selain izin standar yang otomatis diberikan sistem Android untuk menjalankan aplikasi.

Pihak ketiga

Aplikasi ini tidak mengintegrasikan layanan pihak ketiga mana pun (tidak ada Google Analytics, Firebase, AdMob, atau layanan sejenis).

Anak-anak

Aplikasi ini ditujukan untuk guru/pengajar. Nama santri yang dicatat guru hanya tersimpan di perangkat guru dan tidak dikirim ke mana pun.

Perubahan kebijakan

Jika kebijakan privasi ini berubah (misalnya karena penambahan fitur baru), perubahan akan dipublikasikan di halaman ini dan di listing aplikasi pada Google Play Store.

Kontak

Pertanyaan tentang kebijakan privasi ini dapat disampaikan melalui halaman Issues repository GitHub proyek ini.

Privacy Policy (English summary)

Setoran Tahfidz is an offline-only Qur'an memorization tracker. It collects no data whatsoever. Everything you enter is stored only in your device's local storage, is never transmitted to any server, is excluded from Android auto-backup, and cannot be accessed by the developer. Data leaves the device only when you yourself export a backup file or share a report image. The app requests no special permissions and includes no third-party analytics, ads, or trackers.
